# 产品验收契约

## 产品
本地消费记录小站

## 目标
面向个人用户的纯前端本地消费记账小站，无需后端与网络请求，数据保存在浏览器 localStorage。功能包含：收入/支出记录的增删改查（金额、日期、分类、备注校验，支持时间范围筛选）；汇总看板（总收入、总支出、结余、分类统计，金额统一两位小数）；消费预警（月度预算超支、单笔大额、结余低于下限，阈值可设置，空数据或无设置时不误报）。页面响应式，日期格式 YYYY-MM-DD，非法输入给出明确错误提示。

## 验收标准
1. 自动化测试覆盖记录增删改查、时间范围筛选、汇总统计与三类预警，且全部通过
2. 所有金额显示与计算均为两位小数，日期统一为 YYYY-MM-DD，非法金额/日期/分类/备注输入时显示明确错误且不写入数据
3. 空数据或未设置预算/阈值时，看板显示零值且不产生任何预警提示
4. 页面为响应式纯本地实现，运行期无任何网络 API 请求（可通过静态检查或请求拦截验证）
5. 静态结构测试通过：页面包含记录表单、记录列表、汇总看板、预警与阈值设置区域

## 不可变约束
- 本文件、ACCEPTANCE.md、TEST_PLAN.json 与隐藏验收测试由 Workbench 冻结，Coding Agent 不得修改。
- 验收标准不得为了让实现通过而降低。
- 不新增账户/支付/云端上传敏感数据，除非用户另行明确授权。
