# 使用说明

## 第一次使用

1. 打开 Workbench。
2. 在中央输入框告诉 AI 你想开发什么（例如“帮我做一个本地阅读管理工具”）。
3. AI 会整理产品名称、目标和可验收标准；信息不足时只问必要问题。
4. 确认需求草案后点“开始开发”。
5. 页面显示正在规划/编码/测试/审计；点“展开真实工程详情”可查看真实任务、审计、Token、费用和 Git。
6. 完成后在“开发详情”中查看证据并人工验收。Workbench 不会自动合并 main 或部署。

## 已有项目

左侧“我的项目”选择已有项目，再输入本次开发目标；不会覆盖原有 Git 历史与验收记录。

## 高级模式

所有原有工程能力在 `/advanced`（开发详情）保留：项目、运行、任务、Agent、独立审计、质量矩阵、Supervisor、Git/CI、预算、回放、日志、暂停/恢复/取消。

## 设置

可切换浅色/深色/跟随系统；查看预算；打开开发详情。界面尊重系统减少动态效果设置。

## 阻塞

若看到“开发暂停，需要你处理”，展开详情查看真实原因；常见为预算/权限/Docker 隔离/审计授权。界面不会擅自提高预算或突破安全边界。
